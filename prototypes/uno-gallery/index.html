    Get started

    Three steps from a copied sample to a running app.

    1. Step 1

      Create the app

      Install the templates once, then create a project.

      dotnet new install Uno.Templates
      dotnet new unoapp -o NightDrive
    2. Step 2

      Turn on the features

      Toolkit samples need Toolkit, FeedView needs MVUX, and the Material previews need Material in your project file.

      <UnoFeatures>Material;Toolkit;MVUX;CSharpMarkup</UnoFeatures>
    3. Step 3

      Paste and run

      Copy a sample into a page, then start the desktop head to check it before you deploy.

      dotnet run -f net10.0-desktop
